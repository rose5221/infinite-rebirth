# v5 世界稿 · 第二批（扩写密度）

审阅要点：每个世界现在都有 婴幼2 / 童年4 / 少年4 / 谋生5 / 世界5 / 随机3 段，围绕一条“家庭线 + 一条文明规则线”。

## 四、无昼京（东方城池 · 漏钱）
**规则**：朝廷按身份配给日照，权贵买白昼，百姓靠夜作。日门开启才算一日，城外黑暗会吞没未标记的路。
**家庭**：父亲亥叔（夜脚夫）、母亲灯娘（修灯匠）、手足小漏（抄漏吏）。

| 阶段 | 新增场景 | 要点 |
|---|---|---|
| 童年 | 灯娘教认光 | 教你分三种光：配给的、偷来的、死人留下的 |
| 童年 | 街上的更夫 | 多敲一下，第二天那条街少了半个时辰 |
| 少年 | 影市 | 只卖别人不要的光、时辰、影子 |
| 少年 | 夜脚夫的腿 | 父亲腿先坏，然后是眼睛 |
| 谋生 | 妹妹的抄漏 | 抄错一笔就少算一户人家的光时，那户昨天搬走了 |
| 谋生 | 一场停光 | 日门迟开，有人不在原来的位置 |
| 世界 | 光时账 | 全城光时每年少一点，没人知道少在哪 |
| 世界 | 父亲的第一日 | 父亲一辈子只见三次真正的白天 |

**这一界最狠的**：父亲说“第三次是今天”。不是长生，是数得过来的三次。

## 五、井垂天（井中世界 · 涟钱）
**规则**：井底另有天空与雨源，井主垄断取水。旅行要沿井索下降到倒影世界再上行。
**家庭**：父亲绳伯（守绳人）、母亲桶娘（修桶匠）、手足小涟（井壁农）。

| 阶段 | 新增场景 | 要点 |
|---|---|---|
| 童年 | 井底的雨 | 雨往上落，父亲说那是另一边的天在漏 |
| 童年 | 守绳的三条规矩 | 结打双、绳摸一遍、听见有人叫不要停 |
| 少年 | 按井深收税 | 井越深税越重，父亲说“深有深的道理” |
| 少年 | 井壁上的画 | 妹妹画井底的天，那里的人倒着走 |
| 谋生 | 桶底的账 | 母亲修桶半辈子，账全记在桶底，一笔不差 |
| 谋生 | 塌井 | 救人要下井，下井可能就上不来 |
| 世界 | 老十岁的倒影 | 井水里看见自己老十岁；父亲也见过，他看见的是年轻十岁的自己 |
| 世界 | 井下的名字 | 守绳人死了，名字留在井下，下一任放绳时念一遍 |

**这一界最狠的**：父亲问“以后你会念我的名字吗”。

## 六、逆轨环城（轨道科幻 · 转矩票）
**规则**：城市沿反向轨道环行，每次变轨以角动量结算；微陨石来时只能保一侧。
**家庭**：父亲轮叔（环带维修工）、母亲秤娘（飞轮农）、手足小轨（信使学徒）。

| 阶段 | 新增场景 | 要点 |
|---|---|---|
| 童年 | 蚀里的数数 | 数到六百六十下光才回来；母亲数错过一次 |
| 童年 | 工服上的补丁 | 每块补丁对应一次险情，补丁就是资历 |
| 少年 | 飞轮的份例 | 轮子转得慢，菜长得慢，份例没减 |
| 少年 | 妹妹的制动课 | 排第一，却问“制动就是让别人先停，这算天赋吗” |
| 谋生 | 母亲的飞轮 | 出过故障，断三根肋骨，从此懂什么叫“持续运动岗” |
| 谋生 | 重登相位 | 登记错的人成了“无票乘员” |
| 世界 | 刹轮贵族的宴 | 他们谈角动量像谈酒，没人问谁被甩出去过 |
| 世界 | 父亲的一次刹车 | 陨石来那一秒，他把刹车推向农场，船坞死了人 |

**这一界最狠的**：父亲问“你觉得我做对了吗”。没有正确答案。

## 七、髓云都市（记忆科幻 · 忆质）
**规则**：记忆可结晶成货币；删除会留下七分钟人生空洞；建筑靠居民共同记忆维持。
**家庭**：父亲砚叔（记忆采集师）、母亲雾娘（封忆师）、手足小忆（记忆学徒）。

| 阶段 | 新增场景 | 要点 |
|---|---|---|
| 童年 | 学校的记忆课 | 教整理记忆，说整理好能卖好价钱 |
| 童年 | 父亲的采集器 | 把别人回忆抽进雾晶，那人脸上什么也没有 |
| 少年 | 雾晶的价格 | 一段高纯度童年值一个月饭钱 |
| 少年 | 母亲的封忆匣 | 一排匣子贴着日期，从不打开也不扔 |
| 谋生 | 父亲的职业债 | 做了三十年采集师，自己的记忆被磨得很薄，有时问你“你是我儿子吧” |
| 谋生 | 一次归档事故 | 一条街同时失去同一年的记忆 |
| 世界 | 无名者的记忆 | 一段没有主人的记忆：孩子等到天黑 |
| 世界 | 母亲十七岁的下午 | 她在河边等一个人，那人没来 |

**这一界最狠的**：父亲问你“我有没有忘掉什么重要的事”。

## 八、钟葬群岛（西幻海岛 · 潮铢）
**规则**：亡者要敲钟偿还复活消耗的潮水；丧钟一响全岛倒退一刻，只有持蚌壳的人记得。
**家庭**：父亲钟伯（守钟人）、母亲潮娘（捞钟客）、手足小铢（殡仪船工）。

| 阶段 | 新增场景 | 要点 |
|---|---|---|
| 童年 | 第一次海葬 | 棺沉下去全岛钟响一下，耳朵疼三天 |
| 童年 | 父亲坏掉的耳朵 | 守钟人的耳朵都要坏，坏了才算入行 |
| 少年 | 潮铢掺铅 | 有人往钟铜掺铅，罚听一夜哑钟 |
| 少年 | 妹妹想上岛 | 没钟的地方不算活人 |
| 谋生 | 母亲耳朵里的水 | 她说水下能听见沉钟在喊活人名字 |
| 谋生 | 一场伪潮 | 潮没按历法来，淹了半个村，议会说不是他们的错 |
| 世界 | 第九口钟 | 本来九口钟，少的两口被从钟谱上撕掉 |
| 世界 | 第七口钟 | 父亲说等他死，第七口会裂，名字刻进裂缝 |

**这一界最狠的**：父亲问“你愿意接第七口吗”。

## 借寿渡 / 星耒野 / 空白修院 的追加

- **借寿渡**：补了母亲线——她说自己不记得多大年纪，嫁到渡口后日子按葬礼算。
- **星耒野**：补了母亲线——舂星糠的人梦越来越短，因为光被舂碎了。
- **空白修院**：按你的意见改成父亲线。新增「父亲的空缺」（谱上他的名字后是留白）、「父亲笔下的自己」（他把自己的那一页撕下来给你，说这半生就当没写过）；原来“母亲忘掉自己”换成了「墨池守的规矩」（听见有人叫你，不要应）。
