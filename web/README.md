# 无限重生 · 此世（网站版 v5.2）

网页包本身不含 IPA；iOS v4 未签名包在 `桌面/无限重生系统-v4-未签名.ipa`。

## 部署成随时能玩的网站

这是纯静态网页，可放到任意静态托管：

- 本机：`python3 -m http.server 8890`，访问 http://127.0.0.1:8890
- 手机同网络：把 127.0.0.1 换成电脑局域网 IP（如 http://172.20.10.2:8890）
- 公网：把整个 `web/` 目录上传到 Netlify / Vercel / Cloudflare Pages / GitHub Pages，无需后端
- 手机浏览器打开后“添加到主屏幕”，可全屏像 App 一样运行；带离线缓存，断网也能继续玩（进度存本机）

AI 是可选的：右上角 ⚙ 填自己的 DeepSeek Key 才启用；不填时全部用本地叙事，不影响年龄、事件链、记忆、关系与结算。

## 打开

- 直接双击 `index.html` 可玩离线模式；进度存在当前浏览器 localStorage。
- 需要 AI 时在本目录运行 `python3 -m http.server 8890`，访问 `http://127.0.0.1:8890`（手机用电脑局域网地址）。不要用 `file://` 测试 DeepSeek，浏览器跨域来源会不同。
- 右上角“档”查看轮回档案，“?”查看规则，“⚙”填写接口。

## v5.2（当前站包）

- **默认 0 岁**：取消年龄输入，每一世都从出生开始。
- **选择即时反馈**：每次说话/行动后，对话区下方立刻显示情绪变化芯片（喜 +3 / 惧 -2 等）；这一段结束的结算页列出所有加成（收入、支出、属性、健康、现钱、亲近）。
- **人物线修复**：以前 0 岁开局不会生成家人以外的 NPC，人物页只有家人、关系场景永不触发。现在 13 岁起自动认识 2 位社会人物，人物页可直接闲谈、共同经历、表明心意、一起过日子，并真实推进时间。
- **每个世界独立地图**：66 界各有布局（环形/一线/垂直/网格/辐射/沿河/两岸/塔层），节点之间要沿真实道路移动，越远越耗时、越费盘缠。
- **带记忆重生**：死亡后可选择带着姓名、性别、属性、天赋和这一世最深的几段记忆，随机投到另一个世界，从 0 岁重新出生；新一世出生时会看到"前世的影子"。

## v5 人生模拟器

- **年龄真分幕**：婴幼（0-3）家庭蒙太奇、幼年（4-6）、童年（7-12）、少年（13-18）、青年（19-30）、中年（31-50）、晚年（51-70）、余晖（71+）。0 岁开局从出生与家人开始。
- **四拍片段**：发生了什么 → 你怎么做（可打字、可沉默）→ 短期回应 → 长期结算。不再每段都有 NPC 提问。
- **场景类型混合**：旁白叙事、人物对话、时间蒙太奇、余波、过渡章。人物对话只占少数。
- **事件导演**：年龄必需场景 → 未完成事件链 → 人物弧 → 世界/随机事件 → 阶段专属事件 → 过渡章；带近期去重。
- **6 个深度世界**：穗骨原、无昼京、井垂天、逆轨环城、髓云都市、钟葬群岛，含家庭、童年、少年、谋生链、世界规则链、随机事件与人物。
- **记忆库**：每次结算存长期记忆，下一段会浮现旧事，AI 对话会读取；记忆是导演输入。
- **情绪七情**：影响工作、冒险、关系与叙事结果。
- **经济**：生活成本随收入与积蓄上涨；无固定雇主时只有零活收入；58 岁后退休，靠养老金与积蓄。
- **英文回顾**：每段结算后把这一段的英文版放在可折叠卡片里，默认收起，自己决定读不读；不再有单词卡和“考研词/已记住”。
- **AI 只写文本、扮演人物**；分支、时间、关系、数值由本地规则决定，无 Key 也能完整游玩。

## 旧版月度对话（v4.2 已由 v5 取代）

- 主入口不再是一次性年度选项，而是 **一段人生场景**：点“此刻”，阅读开场，输入回复，和 NPC 进行 2-5 个来回，然后“结束这一段”。时间长度按场景随机，不再强行一个月。
- 每段结算收入、生活成本、情绪、人物关系和英语学习成果，再点“继续人生”。
- 主线有连续阶段：选择生活方向（工作/求学/旅行/定居）→ 第一份差事/求学/上路 → 工钱或学业 → 地方风波 → 势力邀请 → 世界规则裂缝 → 留下来或离开；选择会写入后续场景。
- 性别可选，年龄可从 0 岁开始；幼年/童年/少年使用独立场景，不强制工作开局；有职业后显示职业名，而不是“无业游民”。
- 人物线会插入月度场景：初识、来往、深谈、未说出口的话、恋爱日常、久未联系；关系达成后不会停在成就，会继续有对话和代价。
- 情绪系统：喜/怒/哀/惧/爱/恶/欲七项，随输入内容变化，并影响录用、冒险与关系结果。
- 英语移到每段结算页：从故事和场景中抽三个考研常见词，点记住进入永久词库；人生终点汇总。
- 记忆库：每次结算存入长期记忆，后续场景开头会浮现相关记忆，AI 对话也会引用；不再是无连接的随机事件。

## v4 变化

- **66 个世界重新定义**：按 WorldViewGenerator 的 16 维社会清单与四阶段压缩法重写；见 `WORLD-BIBLE-66.md`，含 66 种独立货币、势力、时间轴、地点和事件方向。
- **天赋构筑**：26 种天赋（含隐藏成长形态），普通天赋有稳定路线，SSS/UR 带寿限、收入、健康或生活成本代价；同流派有互斥组合；达到条件可成长（如薄田→庄园主、穷理→一方学者、预支传奇→还债之人）。
- **人生闭环**：四维属性、年龄阶段、事件条件、选择结算、职业成长、人物关系、人生旗标、个人编年史、成就和结局评价。
- **人物线**：每界生成可长期交往的 NPC，关系从陌生→相识→好友→知己→恋人；交谈、共同经历、表明心意都会消耗真实时间，并可能留下知己或恋人。
- **随机世界事件**：除固定事件外，每 3 个节点按当前世界的势力、地点、风险和物产动态生成事件；带权重、条件、选项效果和近期避重，借鉴 ai-events 的数据契约而不直接搬时政内容。
- **每幕英语**：每次选择后显示 3 个场景英语词/短语，点击记住后进入永久词库；人生结局汇总“这一生学到的英语”，跨轮回保留。
- **世界深化**：世界档案按 worldbuilding 流程显示核心偏离与七层后果链，16 维社会、势力、时间轴、地点均可查。
- **经济重调**：每次主要选择约消耗一年；工作年收入与生活成本分开结算；续命药基础价 **120,000**，之后每颗 **×1.8**，再乘每日汇率和天赋修正。首颗按初始收入约需多年经营，不再是玩一会就能买到。
- **空间与时间**：地图旅行按年消耗盘缠；年龄、寿限、健康和年度生活成本实际推进。
- **DeepSeek 直连**：文本接口默认 `https://api.deepseek.com/v1/chat/completions`，模型 `deepseek-chat`。不需要 Mac 转发或本地代理；浏览器直连已确认 DeepSeek 允许来自本地服务器的跨域请求。需要填写你自己的 API Key。
- **原创画像**：`portraits/` 内有 66 张按世界程序化生成的原创氛围画像，默认直接使用；可选火山方舟 Seedream 图片接口生成事件专属画像，失败不会中断文字。
- **操控修复**：禁用双指/双击缩放；选择后停在结果页，必须点“确定，进入下一幕”；加天赋/加点不再跳回顶部；搜索框局部刷新；点空白收起键盘。
- **全部本地**：无账号、无云存档；删除站点数据会删除进度。

## 校验

```sh
cd web && python3 validate_worlds.py
```

输出 `WORLD_BIBLE_VALID` 表示 66 世界、66 货币、16 维字段、3 个势力、4 个时间节点与 4 个地点均齐全。

## 试玩重点

1. 天赋是否真的各有取舍，尤其 SSS/UR 的代价是否可感知。
2. 工作、生活成本、续命药的时间尺度是否合理。
3. 事件是否足够多样、是否跟世界文明和年龄阶段有关。
4. 手机竖屏阅读与操作是否顺畅。

参考项目只借鉴机制：状态驱动提示词、结构化事件、视觉锚点、文体与图片解耦、成就/结局。没有复制其素材、文案或代码。
