# v5.0 网页测试版

## 打开
- 双击 `index.html` 可离线玩。
- 要接 DeepSeek：在本目录运行 `python3 -m http.server 8890`，访问 http://127.0.0.1:8890，右上角 ⚙ 填 Key。不填也能完整玩，NPC 用本地叙事。

## 这版改了什么
1. 年龄真分幕：婴幼 0-3 / 幼年 4-6 / 童年 7-12 / 少年 13-18 / 青年 19-30 / 中年 31-50 / 晚年 51-70 / 余晖 71+。
2. 0 岁开局从出生和家人开始，不再问"你打算靠什么活下去"。
3. 场景四拍：发生了什么 → 你怎么做（可打字、也可不回应直接结束）→ 短期回应 → 长期结算。
4. 场景混合：旁白/岁月/对话/余波。实测 24 段中对话只 2-6 段，其余是事件和岁月。
5. 事件导演按年龄与记忆选事，近期场景去重。
6. 6 个深度世界：穗骨原、无昼京、井垂天、逆轨环城、髓云都市、钟葬群岛。
7. 记忆库：每段存一条，之后会"旧事"浮现，AI 对话也读它。
8. 七情影响工作、冒险、关系。
9. 有具体职业/学生/旅人/老人称谓，不再永远"无业游民"。
10. 英语每段抽 3 个与该段剧情相关的考研词；结局分开统计"遇见"和"主动记住"。
11. 经济：未成年不扣生活费；成年按零活/工资结算；58 岁退休；钱越多生活成本越高，一生攒不下暴富。

## 测试重点
- 0 岁、7 岁、16 岁、25 岁各开一局，看场景是否符合年龄。
- 连续玩 20 段，统计有几次是"某人问你"。
- 关系是否在后续几段后仍有回响。
- 是否出现重复标题、时间跳得太快或太慢。
- 不填 Key 时文本是否还能读得下去。

## 本批更新（2026-10-29 晚）
- 移除单词卡与“考研词 / 已记住”。改为“这一段发生的事”的英文回顾：默认收起，可点“译成英文”展开；填了 DeepSeek Key 时会在后台自动翻译，不填则给一段纯英文简版。
- 新增三个深度世界：借寿渡、星耒野、空白修院（含家庭、婴幼/童年/少年/谋生/世界/随机事件）。
- 网页升级为可安装 PWA：手机浏览器“添加到主屏幕”可全屏运行；HTML 走网络优先，资源离线缓存，断网仍可玩。
- 修复重开一局时家庭与场景进度未重置的问题。

## 部署成网站
把整个 web 目录上传到任意静态托管即可（Netlify / Vercel / Cloudflare Pages / GitHub Pages）。入口 index.html，无需后端。
