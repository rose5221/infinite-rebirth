## 一、借寿渡（阴阳民俗 · 阳楮）

**核心规则**：渡口以寿数抵押维持阴阳通航；赊寿葬亲，债越积越深。河每逢大葬改道，村子会被冲到对岸。

**家庭**：父亲楮老渡（渡工）、母亲棺娘（棺木匠）、手足小楮（哭丧学徒）。家住在沉碑渡。

| 阶段 | 场景 | 要点 |
|---|---|---|
| 婴幼 | 满月与丧事 | 满月要摸棺木，免得被水里的东西认错 |
| 婴幼 | 赊来的寿 | 长辈葬礼是赊的，父亲按手印用往后寿数抵账，此后咳嗽变多 |
| 童年 | 第一次撑船 | 独自送一具空棺过河，水里有人在数你的心跳 |
| 童年 | 棺木匠的手 | 母亲钉棺从不问死者是谁，让你扶木板 |
| 童年 | 替人哭一场 | 无人认领的死者，白衣孝会出钱请人哭丧 |
| 少年 | 父亲的寿数 | 簿子上父亲的寿数已抵掉一半，他问你接不接船 |
| 少年 | 河改了道 | 大葬后河流改道，把对岸村子冲到这边，坟不知在哪岸 |
| 少年 | 哭丧学徒 | 手足嗓子哭哑，分不清哪次是真难过 |
| 谋生 | 接船 | 接过渡牌，渡客里有不肯承认自己已死的人 |
| 谋生 | 寿漕司的账 | 父亲抵的寿数不够，要拿你的补 |
| 谋生 | 赊一场葬礼 | 村里死人拿不出寿数，跪在渡口求你摆渡 |
| 谋生 | 母亲的棺 | 母亲给自己打薄棺停在屋后，每天擦一遍 |
| 世界 | 亡者持牌 | 夜里渡客递来的渡牌，写着你父亲的名字 |
| 世界 | 沉碑帮 | 从水里捞起刻着你名字的碑 |
| 世界 | 大潮 | 寿漕司封渡，白衣孝会点灯说不封，你开不开船 |
| 世界 | 手足的账 | 手足把攒的寿数全抵给家里，问你以后会不会也这样 |

**想请你确认**：这世界的主线是"寿数即货币"，最狠的一刀是母亲提前给自己打棺。这个方向要不要保留，还是太沉了？

## 二、星耒野（星辰农耕 · 星糠）

**核心规则**：星粒种在黑水田里，收光热；收多了，夜路、航运与游魂就失去方向。

**家庭**：父亲星老耒（夜灌农）、母亲糠娘（舂星工）、手足小耒（扎草人匠）。住在暗河村。

| 阶段 | 场景 | 要点 |
|---|---|---|
| 婴幼 | 夜里的田 | 襁褓就被放到星田边，说长大才看得见星 |
| 婴幼 | 一次阴天 | 半月看不见星，官月推迟，星糠分成更小的份 |
| 童年 | 第一次下田 | 水下是没有尽头的夜，父亲说别往下看，看星 |
| 童年 | 舂星的手 | 母亲手上全是白点，夜里会发亮 |
| 童年 | 草人 | 手足扎草人给游魂指路，有一夜草人换了位置 |
| 少年 | 星位 | 父亲教看星位，错一次一季白干 |
| 少年 | 司辰庄来收星 | 份例涨了，母亲推走最后一袋，父亲不说话 |
| 少年 | 夜路 | 星收得太多，路边没有影子，夜路认不出人 |
| 谋生 | 浅田第一季 | 分到浅田，星疏水浅，父亲说浅田不易沉 |
| 谋生 | 抢灌 | 上游夜里开闸，田里只剩黑 |
| 谋生 | 暗河渔盟 | 能帮你把水引回来，但要你送不该送的东西 |
| 谋生 | 收成 | 星糠能吃饱，只是梦会短一点 |
| 世界 | 田底的门 | 田底裂开透光，下面是另一个夜空，有人往上看你 |
| 世界 | 草人的名字 | 手足在草人身上写死者与自己的名字 |
| 世界 | 午夜蚀光 | 司辰庄校准星历，全野星田同时黑，人们喊亲人名字 |
| 世界 | 父亲的眼睛 | 父亲看不清星位，把记星位的本子交给你 |

**想请你确认**：这世界的"梦会短一点"是我加的代价设定，要不要保留？它让"吃饱"变得有阴影。

## 三、空白修院（姓名悬疑 · 墨疤）

**核心规则**：修院鼓励舍弃姓名，靠贩卖遗失身份维持财富；说出真名能开门，写下他人真名会夺走其一段人生。

**家庭**：父亲无咎（抄谱杂役）、母亲墨娘（墨池守）、手足小页（无名童）。住在白页回廊。

| 阶段 | 场景 | 要点 |
|---|---|---|
| 婴幼 | 名字被写下的那天 | 孩子不取名，只刻墨疤；母亲在你耳边说三个字，随即让你忘掉 |
| 婴幼 | 回声室 | 哭太久被抱进回声室，屋子把哭声还给你，直到忘记为何哭 |
| 童年 | 抄自己的名字 | 没有名字，只能抄一百遍「空」，抄到字不成字 |
| 童年 | 母亲的真名 | 母亲喝醉说漏两个字，随即捂嘴 |
| 童年 | 会走路的房间 | 门牌被撕掉后，再没人找得到那个房间 |
| 少年 | 父亲的笔迹 | 替父亲抄谱，抄错一个字，那个人就少活一天 |
| 少年 | 寻名者 | 能查出你的真名，代价是抄一份禁书 |
| 少年 | 手足的名字 | 手足偷偷给自己取名，藏在砖缝里 |
| 谋生 | 保管姓名 | 替香客保管姓名，有人三年不来取 |
| 谋生 | 无名议会 | 三个名字被取走，取走的人早已死了 |
| 谋生 | 墨池 | 池底沉着被刮掉的名字，捞墨时有人叫你 |
| 谋生 | 香客的谢礼 | 取回名字的人说：谢谢你记住我还是谁 |
| 世界 | 真名目录 | 禁书里写着整个修院的真名，翻到中间看见自家姓氏 |
| 世界 | 父亲的罪 | 父亲年轻时刮掉过一个名字，那人死在门外无人认领 |
| 世界 | 钟声消失 | 有人写下院长真名，所有钟同时失声，查到谁谁就少一段人生 |
| 世界 | 母亲问我是谁 | 母亲开始记不住事情，认得你的脸却叫不出名字 |

**想请你确认**：这世界的核心痛点是"母亲忘掉自己"，和借寿渡的"母亲提前打棺"有点像。要不要把空白修院换成父亲线，避免重复？
